# g-fluid v2（スペクトル流体・円環の噴出口）設計

- 作成：2026-10-10。設計は Opus、実装は impl-sonnet。
- 状態：SSOT。
- 現行の g-fluid（WorldFluidAnalyzer と、engine 側の世界流体・emitter・particles・feedback）を置き換える。id `g-fluid`、ラベル「スペクトル流体」、key 1 は引き継ぐ。

## 0. オーナーの指摘（設計の制約）

- 音楽によって変化していると感じられない。何が原因で変化しているか分からない。
- 小さい粒子はちらつくだけで美しくない。煌びやかに瞬くなら美しい。
- 遠近感や空間的な広がりがない。どこにもフォーカスしていない。主題・副題・背景が分からない。
- 水面が揺れるような表現は美しくない。
- 細かく切り替わるより、大きくうねっている方が良い。
- 周波数ごとの音量の変化が感じられないと退屈。
- レガシー版の円形アナライザーは格好良い。

## 1. 構成（主題・副題・背景）

| 層 | 内容 | 音との対応 |
|---|---|---|
| 主題 | 画面中央の **円環の噴出口**。32 個の噴出口が円に並び、帯域ごとの色の光るインクを外へ噴き出す。円環そのものも、帯域ごとに光る。 | 帯域 i の音量 → 噴出口 i の噴出量と光。キック → 円環から外へ圧力の輪。 |
| 副題 | 噴き出したインクが、大きくゆっくり回る渦に巻かれて、渦巻きの腕になって流れ出す。 | 音量 → 渦の回転の速さ。展開 → 渦の強さ。 |
| 背景 | 奥行きの違う塵の 2 層と、中心のほのかな霞。カメラがゆっくり動くと視差が出る。 | 高域のオンセット → 星のような瞬き（光の十字）。 |

- 水面のような陰影（法線、スペキュラー）は使わない。インクは発光体としてだけ描く。

## 2. 流体ソルバー（自己完結。engine の WorldFluid は使わない）

- 新規ファイル `js/world/g-fluid2.js`。クラスは `WorldFluid2Analyzer`、id は `'g-fluid'`。
- 座標：画面の中心が原点。y は [-1, 1]、x は [-aspect, aspect]。
- 格子：
  - 速度：VEL_W × VEL_H = 384 × 216（RG16F の ping-pong）
  - 圧力：同じ大きさ
  - 染料：DYE_W × DYE_H = 1152 × 648（RGBA16F の ping-pong）
- 1 ステップ（dt = 1/60 の固定。renderAt と export でも同じ）：
  1. 速度の半ラグランジュ移流。速度の減衰 `v *= exp(-VEL_DAMP*dt)`、VEL_DAMP = .6。
  2. 背景の流れへの緩和：`v += (v_bg - v) * BG_RELAX * dt`、BG_RELAX = .8。§3 を参照。
  3. 噴出口の力（§4）とキックの衝撃（§5）を加える。
  4. 渦度閉じ込め：ε = VORT = 14（格子セル/秒の単位）。
  5. 発散を求め、圧力を Jacobi 法で 24 回反復し（前フレームの圧力を初期値にする）、勾配を引く。
  6. 染料の移流と減衰：`dye *= exp(-DYE_DECAY*dt)`、DYE_DECAY = .35（区間ごとの倍率は §7）。噴出口の染料（§4）を加える。
  7. 境界：画面端から EDGE = .06 の範囲で、染料と速度を `smoothstep` で 0 へ落とす（吸収境界）。
- 速度の単位は「世界単位/秒」とする。移流では格子の大きさで変換する。

## 3. 背景の流れ（大きくゆっくりうねる）

- `v_bg(p) = Ω × (p - C)` の回転流に、大規模なカールノイズを足す。
  - `Ω = OMEGA_BASE * (OMEGA_FLOOR + OMEGA_LOUD*loudness) * sectionOmega`
    - OMEGA_BASE = .22 rad/s
    - OMEGA_FLOOR = .6、OMEGA_LOUD = .8
  - 回転の強さは中心からの距離で減衰させる：`* exp(-|p-C|²/(2*.7²))`。
  - カールノイズ：スケール 1.2、時間周波数 .03Hz、振幅 CURL_AMP = .06 世界単位/秒。
- C は画面中心（0, 0）で固定する。

## 4. 主題：円環の噴出口

- 半径 R0 = .27。噴出口 i（0..31）の角度は `θ_i = -π/2 + (i + .5) * 2π/32`。帯域 0（低域）が真下から始まり、反時計回りに高域へ進む。
- 位置 `p_i = R0*(cosθ_i, sinθ_i)`。向き `n_i = rotate((cosθ_i, sinθ_i), SWIRL_ANGLE)`。SWIRL_ANGLE = 28°（渦の回転と同じ向き）。
- 帯域の強さ `L_i` は WorldBandAnalyzer の帯域レベル `bands[i].x` を使う。`s_i = pow(L_i, 1.5)`。
- 力：`v += n_i * JET_FORCE * s_i * sectionJet * exp(-|p-p_i|²/(2*.035²)) * dt`。JET_FORCE = 9 世界単位/秒²。
- 染料：`dye += hue_i * JET_DYE * s_i * sectionJet * exp(-|p-p_i|²/(2*.022²)) * dt`。JET_DYE = 6。
- 色 hue_i は帯域の色相の環：`hsv((i/32*.85 + paletteShift) mod 1, .75, 1)`。paletteShift は曲のパレットの primary の色相（曲ごとに環が回る）。
- **円環そのものの描画**（合成パスで、流体の上に重ねる）：
  - 細い光の円 `ring = exp(-((|p|-R0)/.0035)²) * .35`
  - 32 個の光の粒 `nub_i = exp(-|p-p_i|²/(2*.008²)) * (.15 + 1.6*L_i)`
  - 色は hue_i。レガシー版の円形アナライザーを、発光の輪として残す。

## 5. キック（圧力の輪）

- 低域のオンセットのフレームで 1 回だけ（g-gargantua と同じ検出）：`v += r̂ * KICK_PUSH * sectionKick * exp(-((|p|-R0)/.10)²)`。KICK_PUSH = 1.4 世界単位/秒（瞬間の速度増分）。
- 同時に、円環の発光を `(1 + 2.5*kickEnv)` 倍にする。`kickEnv = exp(-(t-lastKick)/.18)`。
- 結果：インクが円環から一斉に外へ押し出され、輪になって広がる。

## 6. 背景：塵の 2 層、霞、瞬き

- カメラ：2D の視点のずれ。
  - `cam = (CAM_AMP*sin(2πt/CAM_PERIOD), CAM_AMP*.6*sin(2πt/(CAM_PERIOD*1.37)))`
  - CAM_AMP = .05、CAM_PERIOD = 40 秒
  - 流体の面は奥行き 1 に置き、`p_screen = p - cam/1` とする。
- 塵：
  - 層 1（奥行き 3）は 3000 点、層 2（奥行き 8）は 9000 点。位置は hash で決める（固定）。
  - 表示位置は `p - cam/depth`。1 画素の点で、明るさ .04〜.12、色は少し青い白（.75, .82, 1）。
  - 遠い層ほど暗く、小さく見える。
- 霞：中心の柔らかい光 `haze = .05 * exp(-|p|²/(2*.45²))` に、パレットの primary の色を付ける。
- **瞬き**（高域のオンセット）：
  - 最大 GLINT_MAX = 24 個。生成のたびに、いちばん強い高域の帯域 k（16..31 で L が最大のもの）の噴出口の外側、`p = (R0 + .1 + .5*hash)*(cosθ_k, sinθ_k) + .03*hashVec` に置く。
  - 形は光の十字。核 `exp(-r²/(2*1.5px²))` に、縦横の光条 `exp(-|y|/1px)*exp(-|x|/14px)` を足す。
  - 明るさの包絡は立ち上がり .06 秒、減衰 .5 秒（`(1-exp(-age/.06))*exp(-age/.5)`）。色は白に hue_k を 30% 混ぜる。
  - ちらつきではなく、ふわっと咲いて消える。

## 7. 区間ごとの変化（展開）

| kind | sectionJet | sectionKick | sectionOmega | DYE_DECAY の倍率 | ズーム |
|---|---|---|---|---|---|
| intro | .6 | .6 | .7 | 1.0 | 1.00 |
| build | .6→1.1（区間の中で線形） | 1.0 | .8→1.3 | 1.0 | 1.00→1.06 |
| drop | 1.4 | 1.5 | 1.4 | 1.15 | 1.08 |
| break | .45 | .4 | .6 | .7（長く漂う） | .94 |
| main | 1.0 | 1.0 | 1.0 | 1.0 | 1.02 |
| outro | 1.0→0（線形） | .5 | .8 | .6 | 1.00→.92 |

- 区間の切り替えは 2 秒の smoothstep で補間する。
- ズームは、画面に表示するときの `p_screen /= zoom` にかける。

## 8. 合成と出力

- 合成パス（シーンのターゲットへ）：`c = 1 - exp(-dye.rgb * EXPOSURE)`。EXPOSURE = 1.6 × (.8 + .4*loudness)。
- これに、円環、霞、塵、瞬きを加算する。その後は既存の post（bloom の閾値 .7、強さ .6）を使い、feedback は使わない（gargantua 分岐と同じ扱いの分岐を post.js に追加する）。
- 毎フレームの経路で配列やオブジェクトを新しく作らない。乱数は hash だけを使う。

## 9. renderAt と決定性

- 状態を持つタイプなので、`warmFrames = 420`（7 秒。DYE_DECAY .35 で .086 まで減衰する）にする。暖機窓の最初のステップで、速度・圧力・染料を 0 にクリアしてから進める（アトラクター §6 と同じ engine の仕組みを使う）。
- ライブ再生と export は 1 ステップずつ進む。

## 10. 統合と撤去

- engine のタイプ一覧で、`g-fluid` を WorldFluid2Analyzer に差し替える。旧 WorldFluidAnalyzer（js/world/g-fluid.js）は登録から外し、ファイルは削除する。
- engine の世界流体（WorldFluid）、particles、depthParticles、post の feedback は、他のタイプから使われていなければ、生成・更新・描画の呼び出しをすべて止める。使われているかどうかは grep で確かめ、判断を log.md に残す。
- 旧 g-fluid に依存する単体テストとブラウザテスト（world12 など、ゴールデンを含む）は、新しい仕様に合わせて書き直すか削除する。削除したテスト ID は log.md に列挙する。

## 11. 受け入れ条件

- **単体テスト**：
  - 噴出口の角度と位置（帯域 0 が真下、反時計回り）。
  - 区間の表と補間。
  - キックの衝撃が 1 フレームだけ加わること。
  - 瞬きの包絡と、生成位置の決定性。
  - 塵の視差の式。
  - warmFrames。
  - 定数の表。
- **Opus の撮影による判定**（renderAt、1280×720、7 区間）：
  - 中央の円環と、そこから渦巻き状に流れるインクの腕が、どの時刻でも主題として読める。
  - 帯域を変えた合成音で、対応する噴出口だけが噴き出す。
  - キックの直後に、インクの輪が外へ広がる。
- **GPU**：1920×1080 で p95 ≤ 16ms。

## 12. 撮影による調整 v2.1（2026-10-10、Opus）

v2 を撮影して、次の 3 点を確認した。

- 円環が主題として読める。瞬きは星のように光る（合格）。
- インクが右下に偏り、色も低域の青緑ばかりになる。音楽は低域が強いので、低域の噴出口ばかり噴くため。
- 回転がほぼ剛体の回転（ガウス関数で減衰する Ω×r）なので、筋が巻き込まれず、円盤状の塊になる。

実験で次の定数に変えた（実装済み）。

- BG_RELAX = 1.5、OMEGA_BASE = .55、CURL_AMP = .03
- SWIRL_ANGLE = 50°、JET_FORCE = 6、JET_DYE = 3.5
- HUE_SAT = .9、VORT = 14（22 では縁がギザギザになった）

残る 2 点は、コードの変更で直す。

- **12.1 帯域ごとの正規化**（JS 側）：
  - 帯域 i ごとに、時定数 NORM_TAU = 4 秒の EMA で平均 m_i を持つ：`m_i += (L_i - m_i)*(1 - exp(-dt/NORM_TAU))`。reset と暖機の開始時の初期値は .2。
  - `n_i = clamp(L_i / max(NORM_FLOOR, m_i*NORM_GAIN), 0, 1)`、NORM_FLOOR = .08、NORM_GAIN = 1.8。
  - 噴出の力、染料、円環の光の粒には、L_i の代わりに n_i を使う（`s = n^1.5`）。
  - uniform `float jetLevels[32]` で送る。
  - 各噴出口は、その帯域自身の盛り上がりで噴く。高域の噴出口も同じように活発に噴く。
- **12.2 差動回転**（背景の流れの §3 を置き換える）：
  - 接線速度は `vθ(r) = Ωeff * (r < R0 ? r : R0*sqrt(R0/r))`。
  - `Ωeff = OMEGA_BASE*(OMEGA_FLOOR + OMEGA_LOUD*loudness)*sectionOmega`。
  - `v_bg = vθ(r) * tangent(p) * smoothstep(2.2, 1.4, r)` に、カールノイズを足す。BG_SIGMA の減衰は廃止する。
  - 外側ほど角速度が遅いので、噴出の筋が渦巻きの腕に巻き上がる。
- 受け入れ条件：7 区間の撮影で、インクが円環の全周から出て、渦巻きの腕になる。色が全帯域に散る。
- 12.3 撮影による追加調整（2026-10-10）：32 個すべてが噴くようになって白飛びしたため、JET_DYE = 2.4、EXPOSURE = 1.25、DYE_DECAY = .9（インクが渦に溜まり続けないように、消える速さを 2.5 倍にした）に変えた。
