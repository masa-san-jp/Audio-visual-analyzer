## 2. Phase 17 音に連動（`js/modulation.js`）

### 2.1 連動元（0..1）

| キー | 表示名 | 値 |
|---|---|---|
| `kick` | キック（低音の打撃） | `onset.env[0]` |
| `snare` | スネア（中音の打撃） | `onset.env[1]` |
| `hat` | ハイハット（高音の打撃） | `onset.env[2]` |
| `beat` | 拍 | テンポ確定時 `(1 − beatPhase)^4`、未確定 0 |
| `downbeat` | 小節の頭 | テンポ確定かつ小節の1拍目のとき `(1 − beatPhase)^4`、それ以外 0 |
| `level` | 音量 | `loudness.level` |
| `bright` | 音の明るさ | `timbre.centroid` |
| `width` | 音の広がり | `stereo.width` |

値は 0..1 にクランプする。

### 2.2 連動先

| キー | 表示名 | 方式 | 幅 | 範囲 |
|---|---|---|---|---|
| `hue` | 色相 | 加算 | 180 | 360 で折り返し |
| `sensitivity` | 感度 | 乗算 | 1 | 0.1〜3 |
| `afterimageIntensity` | 残像強度 | 加算 | 10 | 0〜10 |
| `barWidth` | 線の太さ | 加算 | 10 | 1〜20 |
| `density` | 密度 | 加算 | 70 | 30〜100 |
| `baseOffset` | 基準点オフセット | 加算 | 99 | 0〜99 |
| `motionSpeed` | 動きの速さ | 乗算 | 2 | 0.1〜3 |
| `brightness` | 輝度 | 加算 | 90 | 10〜100 |
| `saturation` | 彩度 | 加算 | 100 | 0〜100 |

```
加算: 値 = 元の値 + 強さ × 幅 × 連動元
乗算: 値 = 元の値 × (1 + 強さ × 幅 × 連動元)
強さ: −1..1（UI では −100〜100）
```

結線は先頭から順に適用し、同じ連動先に複数の結線があれば重ねがけになる。

### 2.3 設定と適用場所

- 設定 `modRoutes`: `[{ source, target, amount }]`、最大4本、既定は空。`normalizeModRoutes` で未知のキーを除き、強さを −1..1 に丸める。プリセット・JSON 保存の対象で、旧形式は空として読み込む
- 適用は `FramePipeline.render` の先頭の1か所だけ（`applyModulation`）。ライブ・オフライン書き出し・自動演出（DirectorRenderer も FramePipeline を使う）で同じ効果になる
- 保存値は変えない。毎フレーム、使い回すオブジェクトに複写した値を変えて描画に使う
- 結線が無い、強さがすべて 0、曲の特徴が無い（AudioWorklet 非対応のフォールバック）のどれかなら、従来と同じ描画（ゴールデン不変）
- GPU タイプには効かない（UI も隠す）

### 2.4 UI

- 「感度・形状」の下にセクション「音に連動」を置く。4行の固定表示で、各行は 連動元（「なし」を含む）・連動先・強さ
- 「おすすめ」ボタン: キック → 感度（+60）、拍 → 残像強度（+40）、音の明るさ → 色相（+25）
- 「すべて解除」ボタン
- ランダムボタンは結線を変えない

## 3. Phase 21 縦型 9:16

| 対象 | 変更 |
|---|---|
| 表示（`visualizer-core.js`） | `aspectRatio: '9:16'` で、表示領域の高さに合わせる（幅が足りなければ幅に合わせる） |
| UI | 「表示比率」に「9:16」ボタンを追加 |
| 2D の書き出し（`offline-exporter.js`） | 1080×1920。未知の比率は 16:9 にする |
| GPU の書き出し（`world-bridge.js`） | 1080×1920。GPU のシェーダーは画面の縦横比から計算する作り（`world-engine.js`）で、縦長も同じ仕組みで扱う |
| 録画（MediaRecorder） | 表示中の canvas を録るため、変更なし |
