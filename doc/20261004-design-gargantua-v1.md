# GPU アナライザー詳細設計：`g-gargantua`（ブラックホール）v1（Opus 設計・Codex 実装）

- Date: `2026-10-04`
- 位置づけ: このタイプの見た目・数式・定数の唯一の正（SSOT）。実装者は書かれたとおりに実装する。
- 目標: 映画『インターステラー』のガルガンチュアに匹敵する、宇宙の壮大さと美しさ。
- 設計の 3 原則（オーナー評価から導いたもの）
  1. **因果が読める**：画面で起きる変化は、すべて音楽の具体的な出来事と 1 対 1 に対応させる。意味の分からないパルス・リング・波紋は入れない。
  2. **階層**：主題（ブラックホールと降着円盤）・副題（光子リングとホットスポット）・背景（重力で歪む星空）を、明るさ・鋭さ・動きの速さで明確に分ける。
  3. **瞬き**：粒や星は、ちらつかせない。星のように煌めかせる（ゆっくりした明滅と、回折の光条）。
- 構想 §2.8 の更新: `g-rings` は削除する（オーナー評価「不要」）。`g-galaxy` は本タイプに置き換える。

## 1. 描画方式：重力レンズの光線追跡

- 全画面のフラグメントシェーダーで描く。**半解像度**（960×540）で計算し、双線形補間で拡大したあと、既存の post（ブルーム・ACES）を通す。
- 単位：シュワルツシルト半径 `Rs = 1`。

### 1.1 カメラ

- 位置は球座標 `(dist, inc, azim)` で、ブラックホールを注視する。上方向は (0,1,0)。
- 視野角 `FOV = 38°`。
- 円盤は y = 0 の平面にある。`inc` は円盤面からの仰角。

### 1.2 光線の積分

ピクセルごとに 1 回行う。シュワルツシルト時空の光の測地線を、デカルト座標で近似する（よく知られた h² 法）。

```
pos = camPos;  dir = normalize(rayDir)
h2  = dot(cross(pos, dir), cross(pos, dir))      // 角運動量の二乗（保存量）
for i in 0..MAX_STEPS(=180):
    r   = length(pos)
    if r < 1.0: hitHorizon; break                 // 事象の地平面 → 真っ黒
    dt  = clamp(r * .045, .015, 1.6)              // 近いほど細かく刻む
    acc = -1.5 * h2 * pos / pow(r, 5.)            // 光の曲がり
    prev = pos
    dir += acc * dt;  pos += dir * dt             // 速度は正規化しない（h² 法の流儀）
    if sign(prev.y) != sign(pos.y):               // 円盤面の通過
        hitPoint = 補間で y = 0 になる点
        rd = length(hitPoint.xz)
        if 3.0 <= rd <= 14.0:                     // 内縁 = ISCO 3Rs、外縁 14Rs
            accumulate disk sample (§2)。透過率 alpha を減らす（最大 3 回まで通過を許す）
    if r > 60.: escaped; break
```

- 地平面に吸い込まれた光線は黒（0）。
- 逃げた光線は、最後の `dir` の向きで背景（§4）を引く。
- 円盤のサンプルは、前から順に合成する：`col += alpha * sampleColor * sampleOpacity;  alpha *= 1 - sampleOpacity`。
- こうすると、**円盤の向こう側が穴の上下に回り込んで見える像**と**光子リング**が、物理的に自然に現れる。

## 2. 降着円盤（主題）

円盤上の点の極座標 `(rd, φ)` での発光を、次のように計算する。

```
// ケプラー回転：内側ほど速い
Ω     = .45 * pow(rd / 3., -1.5) * motionSpeed       // rad/s
φrot  = φ - Ω * t

// 温度と色（黒体放射ふう。内側ほど高温で白く、外側ほど橙から赤へ）
T     = pow(rd / 3., -.75)                           // 1 → 約 0.33
base  = blackbodyRamp(T)                             // §2.1
// パレット（WORLD_PALETTES[dominantChroma]）を 20% だけ混ぜて、曲ごとの色味を出す
tint  = mix(base, base * palette.primary * 1.6, .2)

// 細部：渦巻き状の乱流（細い弧の筋）
q     = vec2(log(rd) * 6.0, φrot * 3.0)
turb  = fbm(vec3(q.x * 2.2, q.y + q.x * .8, t * .05))   // 4 オクターブ
fil   = pow(turb, 2.2) * 1.6 + .25

// 半径方向の包絡：内縁で鋭く立ち上がり、外縁でなめらかに消える
env   = smoothstep(3.0, 3.25, rd) * (1. - smoothstep(10.5, 14.0, rd))

// ドップラー増光（左右の明暗差。ガルガンチュアに合わせて控えめにする）
v     = sqrt(.5 / rd)                                // 円盤の速度（光速比）
beam  = pow(1. / (1. - v * dot(tangent(φ), -viewDir)), 2.2) を [.45, 2.2] にクランプ

I_disk = env * fil * beam * (.35 + 1.4 * pow(3. / rd, 2.))  // 内側ほど明るい
sampleColor   = tint * I_disk * musicGain(rd)        // §3
sampleOpacity = clamp(env * (.55 + fil * .35), 0., .95)
```

### 2.1 `blackbodyRamp(T)`（線形 RGB。T は 0.33〜1）

| T | RGB |
|---|---|
| 0.33 | (1.00, 0.28, 0.05) |
| 0.50 | (1.00, 0.52, 0.18) |
| 0.70 | (1.00, 0.78, 0.48) |
| 0.85 | (1.00, 0.92, 0.80) |
| 1.00 | (0.95, 0.97, 1.00) |

区間ごとに線形補間する。

## 3. 音楽との対応（因果を 1 対 1 にする）

| 音楽の出来事 | 画面の変化 | 式 |
|---|---|---|
| **32 帯域の音量** | 円盤を 32 本の同心の帯に分け、各帯の明るさを帯域の音量で決める。円形アナライザーを宇宙の規模にしたもの | 帯の番号 `k = floor((rd - 3.) / 11. * 32.)`。**外側 = 低域、内側 = 高域**（`band = 31 - k`）。`musicGain(rd) = .45 + 2.2 * L[band]`。隣の帯とは帯幅の 15% だけなめらかに補間する |
| **キック**（低域オンセット） | 円盤の内側 1/3 が、キックと同時に発光する | `kickEnv = exp(-age/.11)`。`rd < 6.5` の部分の `musicGain` に `× (1 + 1.8 * kickEnv * smoothstep(6.5, 3., rd))` を掛ける |
| **高域オンセット**（ハイハット等） | ① 背景の星がきらめく ② 円盤上に光の点（ホットスポット）が生まれて周回する | ① §4 の星の明滅位相を進める。② 最大 12 個のホットスポットを持ち、オンセットごとに 1 個を `rd = 3.5〜8` の決定的な位置に生む。寿命は 6 秒。点はケプラー回転し、ガウス半径 0.18Rs、HDR の明るさ 6 で減衰していく |
| **ラウドネス**（短期） | 全体の露出 | `exposure *= .85 + .3 * loudnessNorm` |
| **セクションの種類** | カメラの距離・仰角・周回速度（下表）。切り替えは 4 秒かけてイーズする | |

| kind | dist | inc | 周回速度 azim'（rad/s） | 円盤の明るさの係数 |
|---|---|---|---|---|
| intro | 40 → 26（セクション内で近づく） | 4° | .010 | .6 |
| build | 26 → 18 | 4° → 9° | .020 → .05 | .8 → 1.1 |
| drop | 15 | 7° | .07 | 1.35 |
| break | 30 | 14° | .012 | .7 |
| outro | 26 → 60（遠ざかる） | 4° | .008 | .9 → 0 |
| main | 22 | 6° | .03 | 1.0 |

- **禁止**：拍ごとの全画面パルス、同心円の衝撃リング、意味のない波紋、ランダムなフラッシュ。
- 2 回目のドロップ（同じ `(kind, label)` の変奏番号が 2 以上）では、dist を 13 に、周回速度を .09 に変え、円盤の明るさの係数を 1.5 倍にする。

## 4. 背景（重力で歪む星空）

- 背景は、逃げた光線の向き `d` から計算する。そのため重力レンズで歪んで見える。
- **星**：方向を立方体マップ風のセルに分ける（`cell = floor(d * 180.)`）。
  - 各セルに、確率 3% で星を 1 つ置く。
  - 明るさは `pow(hash, 18.) * 6.`。色は少し青白から橙までのランダム（ハッシュで決める）。
  - 星は点として描く。半径は 0.6 画素相当。
  - **明滅**：`twinkle = .75 + .25 * sin(phase_star + highOnsetPhase * 1.7)`。`highOnsetPhase` は高域オンセットのたびに +1 する。
  - 明るい星（上位 0.5%）だけ、細い回折の光条（4 方向・長さ 6 画素）を付ける。
- **淡い天の川**：大きなスケールの fbm を 2 層重ねる。明るさは ≤ 0.015。色は `palette.secondary * .4`。
- 背景の明るさの上限は ≤ 0.04。主題より常に 1 桁以上暗くする（階層）。

## 5. 仕上げ

- 既存の post を使う：ブルームの閾値は 1.0、強さは .35、ACES。
- 円盤の内縁と光子リングが、ブルームで美しくにじむこと。
- 被写界深度と前フレームのフィードバックは**使わない**（鋭さを保つ）。
- 性能：1080p 出力（内部は 960×540）で GPU p95 ≤ 16ms（M4 Max）。超えた場合は、MAX_STEPS を 140 まで下げてよい。
