# Audio Visual Analyzer

ブラウザで音声ファイル・動画ファイルを読み込み、再生しながらビジュアライザーを表示するシンプルな Web アプリです。

## デモ

https://youtube.com/shorts/dywUYpVFatw?feature=share

## セットアップ

本プロジェクトは HTML / CSS / JavaScript のみで構成されており、`npm install` などは不要です。

### 方法1: そのまま開く

1. このリポジトリをクローンします。
2. `index.html` を Chrome または Edge で開きます。

### 方法2: ローカルサーバーで開く

直接開けない環境では、リポジトリ直下で簡易サーバーを起動してください。

```bash
python3 -m http.server 8000
```

起動後、ブラウザで `http://localhost:8000` を開きます。

同じ Wi-Fi 上のスマホなどからテストする場合は、`localhost` の代わりに PC の
IP アドレス（Mac / Linux は `ifconfig`、Windows は `ipconfig` で確認）を使って
`http://<PCのIPアドレス>:8000` を開きます。

## 使いかた

1. `ファイルを選択` を押して、音声ファイルまたは動画ファイルを読み込みます（ビジュアライザー表示領域へのドラッグ&ドロップでも読み込めます）。
   - **3つのスロット**にそれぞれファイルを読み込めます。各スロットの `読込` でファイルを設定し、`選択` で再生対象を切り替え、`削除` で外せます。
2. `再生` を押すと、ビジュアライザー表示が始まります。シークバーで任意の位置へ移動でき、音量スライダーで再生音量を調整できます。
   - 再生が終わると次の設定済みスロットへ**自動で循環**します（1スロットのみの場合はループ再生）。`次へ` / `前へ` で手動でも切り替えられます。
3. **アナライザー** セクションで設定を変更します。
   - `タイプ` で棒グラフ / 円形放射を切り替えます。
   - `表現方法` で棒 / 波形線 / 点を選択します。
   - 棒グラフ時は `表示モード` で通常 / ミラー（上下）/ ミラー（左右）を選べます。
   - `アナライザーランダム` でタイプ・表現方法・表示モード・レイヤー数・レイヤー色相オフセットを一括ランダム設定します。
   - `レイヤー数` で1〜4を選択し、多音域表示を試します（2レイヤー以上で各レイヤーの色相オフセット・感度を個別調整可能）。
   - `レイヤー分割` で音域の分け方を 均等 / 聴感（メル尺度）から選べます（レイヤー数2以上で表示）。
4. **色調整** セクションで色を変更します。
   - `色相ランダム` ボタンで色相とレイヤーオフセットをランダマイズします。
   - `色相連続変化` をONにすると、再生中に色相が自動変化します。
5. **感度・形状** セクションで表現を調整します。
   - `音量自動補正` をオンにすると、曲ごとの音量差を自動で補正して見た目の振れ幅をそろえます（既定: オフ）。
   - `密度` で描画要素の数を調整します。
   - `基準点オフセット` で0dB基準位置をずらします。
   - `残像強度` でトレイル効果の強さを変更します。
   - `形状ランダム` で感度・スムージング・線の太さ・密度・基準点オフセット・残像強度を一括ランダム設定します。
6. **録画する場合**は、`録画モード` に切り替えます。
   - `FPS` で録画フレームレート（25 / 29.97 / 30）、`画質` で低 / 標準 / 高を選択できます。
   - `録画開始` を押すと再生と同時に録画が始まります。
   - `録画停止` で録画を終了し、`保存` で録画MIMEに応じた動画ファイル（`.mp4` / `.webm`）をダウンロードします。
   - `再録画` で録画をリセットしてやり直せます。

## スマホでの利用について

狭幅画面（700px以下）では縦積みレイアウト（上にビジュアライザー、下に操作パネル）へ自動で切り替わり、ボタン等のタッチターゲットも拡大されます。以下の点にご注意ください。

- **初回再生**: モバイルの自動再生制限のため、必ず画面を操作して `再生` を押してください。
- **録画**: Android Chrome は動作見込みです。iOS Safari は `MediaRecorder` の
  挙動差（出力形式・ビットレート指定の扱い）があり、録画品質は PC と同等になりません。

## 補足

- 対応するファイル形式はブラウザ依存です。
- 初回再生時はブラウザの制限によりユーザー操作が必要です。
- URL に `?debug=1` を付けて開く（例: `index.html?debug=1`）と、表示領域の左上に FPS・描画時間（平均 / p95 / 最大）・現在のタイプに加え、音楽特徴ストリームの状態（MFS・BPM・拍位相・LUFS・オンセットランプ・受信ホップ数/秒）のデバッグ表示が出ます。録画・書き出しには写りません。付けなければ何も表示されません。
- ライブ表示の解析は AudioWorklet（音楽特徴ストリーム）で行い、出力遅延を補正した時刻の解析結果で描画します。そのため従来より描画が音に対して 10〜40ms 程度遅れて表示されます（見た目はほぼ同じ）。AudioWorklet が使えない環境では従来の `AnalyserNode` 経路へ自動で戻ります。
- 詳細仕様は `doc/spec.md` を参照してください。

## 開発者向けテスト

テストは Node.js 22.4 以上と Chrome / Chromium を使って実行します。依存パッケージのインストールは不要です。

`node tests/run.mjs` で単体テストとブラウザテストを実行します。`--unit` または `--browser` で対象を絞り、`--filter <正規表現>` でテスト ID・名称を指定できます。単体とブラウザの両方を実行する場合は並行して走らせます（順に実行したいときは `--serial`）。ブラウザテストは `tests/browser/*.test.js` を自動検出し、既定では `// @page harness` の生成ハーネスで実行します（`// @page app` は `index.html` に注入。`// @query debug=1` を併記すると `index.html?debug=1` を開きます）。ハーネス HTML は `tests/.generated/` に生成されます。Chrome の自動検出に失敗する環境では `CHROME_PATH` に実行ファイルを指定してください。

GitHub Actions では `pull_request` と `main` への push で `node tests/run.mjs` を実行します。

B15-00 の意図的な失敗テストは、通常実行では「期待どおり失敗したら成功」と反転して判定します。生の判定を確認する場合は `node tests/run.mjs --browser --filter 'B15-00'` を実行してください（pass / fail / fail のため終了コードは 1）。

## 現在の実装内容

### Phase 1 (基本機能)
- 音声 / 動画ファイルの読込
- 再生 / 一時停止 / 停止
- 棒グラフ型アナライザー表示
- 色相・色相幅・輝度・彩度の調整
- 感度・スムージング・棒幅の調整
- 表示比率の切替（16:9 / 1:1）

### Phase 2 (表現拡張)
- 複数アナライザータイプ対応
- 0dB基準位置切替
- レイヤー1〜4対応（音域自動分割）
- レイヤー個別設定（色相オフセット・感度）
- レイヤー分割方式（均等 / 聴感）、音量自動補正（プリセット・JSON 保存の対象）

### Phase 3 (表現拡張・追加仕様)
- **アナライザータイプ切替**: 棒グラフ / 円形放射
- **表現方法切替**: 棒 / 波形線 / 点
- **棒グラフ表示モード**: 通常 / ミラー（上下）/ ミラー（左右）
- **密度調整**: 描画要素数を 30〜100 の範囲で調整（最小でも表示が消えない）
- **基準点オフセット**: 0dB基準位置を最大 99 まで移動
- **線の太さ調整**: 描画要素の太さを変更
- **色相ランダマイズ**: 色相とレイヤーごとの色相オフセットをランダム設定
- **アナライザーランダマイズ**: タイプ・表現方法・表示モード・レイヤー数・レイヤー色相オフセットをワンクリックでランダム設定
- **形状ランダマイズ**: 感度・スムージング・線の太さ・密度・基準点オフセット・残像強度をワンクリックでランダム設定
- **色相連続変化モード**: 再生中に色相が自動的に変化し続ける（変化速度は表示のリフレッシュレートに依存せず、書き出し結果とも同じ速さ）
- **残像表現**: 残像強度を調整し、描画にトレイル効果を付与（過剰設定は上限でクランプ）
- **解析帯域**: 50Hz〜15kHz に限定（超低域・超高域ノイズを除外）
- **レイヤー設定**: アナライザーセクション内に統合

### Phase 6 (拡張表現)
既存の棒グラフ / 円形放射に加え、12種類のアナライザータイプを追加（計14種類）。タイプは「タイプ」セレクトで系統別に選択できます。

- **時間軸系**: スペクトログラム（滝）/ 3D地形 / トンネル
- **擬似3D系**: 擬似3Dバー / 回転3Dリング
- **流体・粒子系**: パーティクル放出 / 波紋 / ノイズフロー / メタボール
- **幾何系**: オシロスコープ（リサージュ）/ 極座標フラワー / ボロノイ脈動
- **追加パラメーター**（選択タイプに応じて表示）: 時間幅（履歴長）/ 動きの速さ / 要素量 / 奥行き角度（3D地形）/ 花弁の数（フラワー）/ 粘性揺らぎ
- 選択タイプが対応しないコントロール（表現方法・表示モード・レイヤー等）は自動的に隠れます。
- 外部ライブラリなし・Canvas 2D のみで実装（擬似3Dは平行投影、メタボールは blur+contrast 合成）。

### 録画機能
- **モード切替**: 再生モード / 録画モード
- **録画**: ビジュアライザー描画領域を音声付きで録画（MP4優先、非対応環境はWebMへフォールバック）
- **MP4互換性**: MP4対応環境では H.264/AAC の一般的なプロファイル候補を優先して選択
- **A/V同期**: AudioContext の再開と録画キャプチャの開始を待ってから再生を始めることで、冒頭の映像・音声のずれを抑制
- **エンコード品質**: 解像度・FPS・画質プリセット（低/標準/高）に応じて映像ビットレートを自動算出（標準時 6〜24Mbps）、音声は192kbps
- **WebM長さ情報**: WebM 出力時はヘッダーに再生時間（Duration）を書き込み、編集ソフトで長さ・シークが正しく扱えるファイルとして保存
- **FPS指定**: 25fps / 29.97fps / 30fps を選択可能
- **操作**: 録画開始 / 停止 / 保存 / 再録画
- **自動命名**: 日時ベースのファイル名で保存（拡張子は `.mp4` / `.webm` を自動判定）

### オフライン書き出し（Phase 7 / Phase 9.1でMP4対応）
音楽ファイルの信号を**再生を伴わず**解析し、現在のビジュアライザー設定に合わせて動画ファイルを書き出す機能です。通常の録画とは独立しており、専用のファイル選択から操作します。

- **決定的な解析**: `OfflineAudioContext` 上で音声全体を解析し、実時間より高速にフレームデータを採取。解析はライブ再生と同一の解析コード（AudioWorklet の音楽特徴ストリーム、`js/mfs-worklet.js`）を優先し、解析粒度もライブと同じになります。非対応環境では `ScriptProcessorNode` + `AnalyserNode` へ自動フォールバック（音楽特徴なし）
- **確定レンダリング**: 実時間再生に依存せず、既存の全アナライザータイプ（棒グラフ〜ボロノイ脈動）を固定フレームレートで1枚ずつ描画
- **WebCodecs エンコード**: `VideoEncoder`（MP4対応環境ではH.264、非対応環境はVP9→VP8フォールバック）と `AudioEncoder`（MP4ではAAC、WebMではOpus）で圧縮
- **自前マクサー**: 外部ライブラリなしで MP4（fragmented MP4、`js/mp4-muxer.js`）/ WebM（`js/webm-muxer.js`）コンテナを新規構築。いずれも **シーク索引**（MP4: `mfra` / WebM: Cues）を書き込むため、通常録画（Duration 後付けのみ）より編集ソフトでの扱いやすさが高い
- **出力解像度**: 16:9 選択時 1920×1080 / 1:1 選択時 1080×1080
- **操作**: 音楽ファイル選択 / FPS選択（25 / 29.97 / 30） / 書き出し開始 / キャンセル / 保存
- **自動命名**: 実際に選定されたコンテナに応じて拡張子（`.mp4` / `.webm`）を自動判定
- 対応ブラウザ: Chrome / Edge（WebCodecs API 対応環境）

### ユーザー向け機能拡張（Phase 8）
- **プリセット保存/読込**: 現在の全設定に名前を付けて `localStorage` に保存し、後から呼び出せます
- **JSON設定入出力**: 設定を JSON ファイルとして書き出し/読み込みできます（プリセットと共通のシリアライズ形式）
- **マイク入力**: 「マイク入力」ボタンでライブのマイク音声をビジュアライザーに反映できます（ファイル再生とは排他）。録画はマイク入力中も利用可能です
- **フルスクリーン表示**: ビジュアライザー表示領域のみをフルスクリーン表示します
- **キーボードショートカット**: `Space` 再生/一時停止、`R` アナライザーランダム、`H` 色相ランダム、`S` 形状ランダム、`F` フルスクリーン、`B` 録画開始/停止（録画モード時）
- **レイヤーごとのブレンドモード**: 各レイヤーに 通常/加算/乗算/スクリーン の合成モードを設定できます（レイヤー数2以上で表示）

### 動画合成表示（Phase 10.1）
動画ファイルを読み込むと表示される「動画合成」セクションで、映像フレームをビジュアライザーの背景として合成できます。

- **合成方式**: 動画を cover フィット（アスペクト比が異なる場合は中央基準でトリミング）でキャンバスへ描画し、その上にアナライザーを重ねます
- **調整項目**: 有効/無効・不透明度（0〜100%）・合成モード（通常/加算/乗算/スクリーン）
- 録画は無改修で動画合成込みの映像を記録できます
- スペクトログラム等、全面を自分で塗り直すアナライザータイプでは動画合成は表示されません

### オフライン書き出しでの動画合成（Phase 10.2 / 14.1で高速化）
オフライン書き出しの対象に動画ファイルを選択し、動画合成を有効にすると、その動画の映像フレームを背景として合成した状態で書き出せます。

- **高速デコード（Phase 14）**: WebM（VP8/VP9）と MP4（H.264）は自前デマルチプレクサ + WebCodecs `VideoDecoder` で映像を直接デコードするため、シーク待ちなしで書き出せます
- **自動フォールバック**: 未対応コンテナ・コーデックや非対応環境では、各出力フレームの時刻へオフスクリーン動画をシークする方式で動作します（速度のみの差で結果は同等）
- **描画仕様**: ライブ表示の動画合成と同一（cover フィット・不透明度・合成モード）
- 動画合成セクションは、オフライン書き出し対象に動画ファイルを選択した場合にも表示されます
- 映像を取得できないファイルの場合は、合成なし（従来どおり音声解析のみ）で書き出しが続行されます

### 画質指定・再生操作性の向上（Phase 11）
- **画質プリセット**: 録画・オフライン書き出しそれぞれで低 / 標準 / 高（0.08 / 0.15 / 0.25 bit/pixel/frame）を選択できます
- **再生シークバー**: 任意の再生位置へ移動でき、現在位置 / 総時間が表示されます
- **音量調整**: 再生音量をスライダーで調整できます（ファイルを切り替えても維持）
- **ドラッグ&ドロップ**: ビジュアライザー表示領域へ音声/動画ファイルをドロップして読み込めます

### 3スロット再生キュー（Phase 12）
- **3スロット**: それぞれに音声/動画ファイルを読み込み、`選択` で再生対象を切り替えられます
- **自動循環**: 再生終了時に次の設定済みスロットへ自動で進みます（スロット1→2→3→1のループ。1スロットのみならループ再生）
- **次へ / 前へ**: 手動でもスロットを循環できます
- 録画モードでは自動循環せず、アクティブスロットのみを対象とします

### 音楽特徴ストリーム（Phase 16 / ライブ経路）
- **AudioWorklet による解析**: 聴感（メル）帯域・オンセット・テンポ/拍位相/小節・ステレオ・音色・クロマ・ラウドネスを約 94 回/秒（48kHz）で抽出（`js/mfs-*.js`）。マイク入力でも同じ経路で解析
- **出力遅延補正**: `getOutputTimestamp()` から「今聞こえている音」の解析結果を選んで描画
- **自動フォールバック**: AudioWorklet が使えない環境やホップが届かない場合は、従来の `AnalyserNode` 経路へ自動で戻る（機能低下のみで動作は継続）
- **解析のリセット**: シーク・停止・スロット切替・ファイル読込で、テンポ推定などを 0 からやり直す
- 既存のレンダラーの見た目は変わりません（`frame.features` は追加のみ）

### ソングマップと自動演出（Phase 18 / ライブ・書き出し）
- ファイル読込後に裏で全曲の拍・小節・セクションを解析し、再生中の拍情報を補強します。
- 「アナライザー」末尾の「自動演出」を ON にすると、曲の展開に合わせてシーンが切り替わります。既定は OFF です。
- 控えめ / 標準 / 激しい、内蔵シーン / マイプリセットを選べます。「別の演出にする」で別の組合せになります。
- ドロップ時のフラッシュは点滅を含みます。フラッシュ OFF または「控えめ」で発光しません。
- 状態欄に解析進捗・BPM・セクション数を表示し、シークバー下に区間の色帯を表示します。マイク入力や非対応環境・解析失敗時は通常描画を続けます。
- 演出中はタイプ・動きなどの操作が無効になります。色・背景・表示比率・動画合成・解析設定はそのまま調整でき、OFF で操作が復帰します。5項目の設定はプリセット・JSON に保存されます。
- 自動演出 ON でオフライン書き出しを開始すると、対象ファイルの解析完了を待ち、ライブと同じ演出設定・プリセットから同じタイムラインで動画を生成します。対象ファイルは再生スロットとは独立して選択できます。
- 解析できない場合も、自動演出なしで書き出しを続けます。解析済みの曲では OFF でもソングマップの拍情報を利用します。

## 用語と表現の選び方

「アナライザー」は音から周波数帯域などの特徴を取り出す側、「ビジュアライザー」はその特徴を棒・線・粒子などの映像へ写す側です。たとえば2レイヤーに分けて色を変えると、低い音域と高い音域の動きを見比べられます。「聴感（メル尺度）」はレイヤーの音域分割方式の選択肢です。録画は再生中の表示を記録し、オフライン書き出しは音を再生せずフレームを生成する別の処理です。

[仕様設計書](doc/spec.md)は、利用者に追加ライブラリのインストールを要求せず、ブラウザ標準APIで始められることを最重要要件にしています。表示領域を主役にし、視認性と直感的な操作を優先する方針が、簡素なUIと外部依存を抑えた構成の背景です。
